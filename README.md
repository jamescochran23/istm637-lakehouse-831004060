This repository contains the Databricks project for ISTM 637, where a governed oil & gas production lakehouse is built using Lakeflow, Genie, dashboards, a predictive model, and a simple notebook-based app.

## Contents

- `ISTM637_Databricks_Project_Starter.ipynb` – main project notebook (Parts 1–5).
- `ISTM637_Predictive_Model_Notebook.ipynb` – model training and forecasting (Part 6).
- `ISTM637_Lakeflow_Ingest_Pipeline.sql` – Lakeflow ingest pipeline definition (Part 2).
- `ISTM 637 Oil & Gas Dashboard FINALvdash.json` – BI dashboard definition (Part 5).
- `Oil Well Production & Forecast Dashboard.ipynb` – history + forecast app (Part 7).
- `Oil and Gas Production Analytics.geniespace.json` – Genie Space export (Part 4).
- `REPORT.md` – written summary of Parts 1–8.
- `screenshots/` – evidence screenshots for each part.

## How to View

1. Import this repo into Databricks as a Git project.
2. Open the starter and predictive notebooks to run queries and models.
3. Use the dashboard JSON and Genie space JSON with Databricks to recreate the BI views.
